# Forseti AI Conversation

Public home for the shared Forseti conversation module: chat UI, conversation history, and LLM integration used across Forseti products.

## Scope

This repository tracks the shared conversation capability used by Forseti properties, including:

- chat-oriented Drupal integration
- persistent conversation storage
- model routing and provider integration
- reusable conversation behaviors shared across products

## Current status

This public repository is being prepared as the standalone home for the shared module. The goal is a smaller, easier-to-consume package than the full `forseti.life` platform workspace.

## Relationship to the platform

- Canonical platform workspace: [`Forseti-Life/forseti.life`](https://github.com/Forseti-Life/forseti.life)
- Intended consumers: Forseti product sites that need reusable AI conversation features

## Planned repository contents

- shared Drupal module code
- installation and configuration guidance
- example integration patterns
- testing and release notes for the extracted package
